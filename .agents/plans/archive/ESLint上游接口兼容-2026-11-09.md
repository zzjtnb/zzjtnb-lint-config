# ESLint上游接口兼容

执行：.agents/tasks/archive/消费配置边界修复-2026-11-09.md

## 当前方案

P01 用户要求保留 antfu 的自动检测、集成 overrides、后置配置及全部 Composer 链式入口。本包只补充已有差异，不缩减上游正式类型。

P02 内层 antfu Composer 原样接收消费选项并仅处理本包生成的配置。外层使用 eslint-flat-config-utils 的正式 composer，依次组合本包插件默认、内层、消费方后置配置；后置 Composer 的原生状态直接传递，其他异步或数组输入在入口归一化。消费方后置配置和后续 override 等操作不进入本包回调，避免同名配置被反向修改；嵌套 Composer 自动传递插件重命名与 Markdown 默认忽略状态。

P03 TypeScript、Vue 原样传给 antfu，不自行检测依赖。仅在上游已生成 Vue 配置时，从上游 Vue helper 提取无障碍默认值，保留显式 a11y:false 和规则覆盖；其他规则通过所属集成的正式 overrides 合并，兼容上游仍支持的旧覆盖字段。

P04 eslint-plugin-format 已是本包直接依赖，当前版本也包含 oxfmt 引擎。通过上游 formatters:{} 仅注册插件，再由消费方限定 files 启用 format/oxfmt；不强制开启格式化，不额外包装 formatter API。TOML 插件及 parser 继续由 antfu 注册。

## 验收标准

P05 自动检测与显式开关、三类覆盖入口、Composer 状态传递、Markdown 原生语言作用域、TOML 覆盖及 Oxfmt 真实修复通过；同步受影响的包文档、工作台资源和独立消费验证。
