# Markdownlint 本项目预设

本页只说明本项目维护的默认差异。上游完整规则、默认选项和推荐配置继续由[上游](/markdownlint/upstream)维护，消费项目只声明需要改变的部分，不重复复制它们。

未覆盖的配置保持继承，消费方同名规则有最终覆盖入口，见[详细配置](/markdownlint/configuration)。

## 本包的规则覆盖

逐项展示上游默认值、本包配置和输入代码触发的诊断。每例先对照“只检查”与“自动修复”的行为，再展示输入和正确写法。正确写法明确标注自动修复结果或手动修正；关闭规则可能允许原输入，并不意味着工具会将它改成正确写法。示例聚焦当前规则，不代表完整预设的全部检查结果。error / warn 是诊断级别，与能否修复无关。支持自动修复的已启用规则在执行修复命令时应用；规则关闭、输入无诊断、不提供自动修复是三种不同情况。编辑器的修正建议需要手动确认，不属于自动修复。

上游对照使用 Markdownlint 原生默认规则。未声明的规则继续使用 Markdownlint 默认状态。覆盖值写入 CLI2 的 config 对象，完整写法见[规则与覆盖](/markdownlint/configuration#规则与覆盖)。

## 共享扫描策略

/config 启用 CLI2 的 Git 忽略，并补充下面的静态扫描排除；只继承包根 JSONC 规则不会带入这些扫描选项。Git 忽略的具体路径由消费项目文件决定，不是一份固定的共享路径列表。

页签中的 JSONC 仅比较扫描字段；实际使用时保留规则 config，或采用完整的“消费方追加”MJS 示例。

::: code-group

```jsonc [本包扫描默认]
{
  // 本包启用 Git 忽略；实际路径随消费项目的 .gitignore 变化。
  "gitignore": true,
  // 本包明确追加的扫描排除；规则仍由 config 继承。
  "ignores": [
    // 依赖安装目录，由包管理器维护。
    "**/node_modules/**",
    // 构建输出或发布制品。
    "**/dist/**",
    // 构建输出或发布制品。
    "**/build/**",
    // 备份副本，不作为当前源码检查。
    "**/backup/**",
  // 代码分析工具生成的索引。
  "**/.codegraph/**",
    // 各层级临时验证与工具材料默认不检查。
    "**/.tmp/**",
  // Git 元数据与工具缓存。
  "**/.git/**",
  "**/.cache/**",
  // 框架服务端构建输出。
  "**/.output/**",
    // 框架生成内容或开发缓存。
    "**/.nuxt/**",
    // 构建、编辑器或部署工具的本地缓存。
    "**/.wrangler/**",
    // 构建输出或发布制品。
    "**/releases/**",
    // 原生工程及其生成内容，由对应工具链管理。
    "**/src-tauri/**"
  ]
}
```

```jsonc [上游 CLI2 默认]
{
  // CLI2 未显式开启时，不自动读取 Git 忽略。
  "gitignore": false,
  // CLI2 默认没有这组共享排除模式。
  "ignores": []
}
```

```js [.markdownlint-cli2.mjs（消费方追加）]
import shared from '@zzjtnb/markdownlint-config/config'

export default {
  // 保留共享规则及扫描选项。
  ...shared,
  // 只追加业务目录，不再复制整套共享排除。
  ignores: [...shared.ignores, '**/generated/**'],
}
```

:::

CLI2 自己的 glob 匹配规则、命令行排除和消费项目其他配置仍会影响扫描。这里的“上游默认”比较的是未声明共享配置时的 gitignore、ignores 字段，不表示所有扫描工具的所有隐式行为都由这两个字段控制。
