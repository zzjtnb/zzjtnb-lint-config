# 文档站视觉设计

主题选型、初始化选项与官方扩展方法见[主题选型与定制指南](./VitePress主题选型与定制指南.md)。本文件只维护本站的具体视觉设计。

## 目标与范围

面向查阅配置、复制示例和排查问题的技术读者，建立清晰、克制且有品牌识别度的文档站。范围为文档站首页、全局导航及正文阅读样式，不改变公开包契约，不重构 Playground 界面。

采用 VitePress 官方默认主题扩展：主题入口使用 `extends: DefaultTheme`，保留官方导航、侧边栏、目录、搜索、复制按钮和移动端菜单。站点正文位于 `src/`；本文件记录本站的具体视觉设计，可在文档站中查阅。

## 视觉方向

以现有 Logo 的蓝色为品牌来源，蓝色与青色只用于品牌强调和首页背景，不把整站正文染成渐变。浅色使用接近白色的冷调背景，深色使用低亮度蓝灰背景，正文保持明确对比。

首页用官方 Hero 和三张产品入口卡片完成主要任务：明确产品是什么、进入快速开始、定位三个共享配置包。卡片直接链接对应指南，不添加重复入口、装饰数据或虚构性能指标。本站仅提供中文页面；公开包的双语 README 保持能力与示例一致。

## 样式职责

| 位置 | 职责 |
| --- | --- |
| `.vitepress/theme/index.ts` | 继承官方主题，加载图标插件 CSS 与站点样式 |
| `.vitepress/theme/styles/variables.scss` | 深浅色品牌、表面、边框与官方主题变量 |
| `.vitepress/theme/styles/custom.scss` | Hero 光晕、卡片状态和导航的少量结构样式 |

仅覆盖实际需要的变量，不复制官方整套变量表。没有独立交互需求时不创建组件或空目录。默认主题的 DOM 类选择器属于升级回归点，不把它们视为永不变化的公共 API。

## 首页与导航

- Hero 标题表达用途，产品名承担品牌识别；桌面和手机均允许自然换行，不缩小正文来挤布局。
- 使用静态径向渐变与原生 Hero 图像光晕，不使用持续动画、视频或额外模糊层。
- 主操作进入快速开始，次操作访问代码仓库；三张卡片分别进入 ESLint、Stylelint、Markdownlint。
- 导航保留官方定位、交互和遮罩；只在支持 `backdrop-filter` 的环境给已滚动导航添加轻量透明模糊，不对整块侧边栏或正文使用模糊。
- 卡片使用细边框与短距离悬停位移，键盘焦点与悬停同样可辨识；不依赖鼠标悬停才提供内容。

## 正文阅读

保留默认主题的正文宽度、字体大小、标题锚点和代码复制交互。代码块、代码组、表格、提示容器使用与背景一致的表面色；保留 warning、danger 的真实语义，不让品牌色覆盖所有状态。

现有代码组图标继续使用 `vitepress-plugin-group-icons`；搜索和最后更新时间继续使用官方能力。图片缩放、PWA、贡献者和提交记录不属于视觉定制的必选依赖。

## 深浅色、响应式与可访问性

品牌文本与背景、按钮文字与填充应达到 WCAG AA 的常规文字对比度 4.5:1。颜色依据具体前景背景组合检查，不以单个色值声称合格。渐变标题属于大字号品牌展示，正文和链接保持纯色可读。

覆盖 390px 手机、768px 平板及 1440px 桌面。长包名与代码可以在自己的容器内换行或滚动，不使整个页面横向溢出。遵循 `prefers-reduced-motion`，减少动态效果；不替换官方焦点管理和菜单键盘行为。

## 验收

1. ESLint、Stylelint 与 Markdownlint 自动修复检查通过。
2. VitePress 客户端、服务端构建与页面渲染通过。
3. 真实浏览器检查中文首页、长文、搜索、菜单、代码组、深浅色切换。
4. 手机、平板、桌面检查布局与溢出，键盘检查操作与焦点，减少动态效果模式不保留卡片位移动画。
5. 独立记录源码、构建与浏览器证据；未执行的检查不视为通过。

继承官方主题降低重复实现的成本，不保证未来版本零维护。升级 VitePress 后重点回归自定义选择器、导航透明度、卡片状态、图标插件与移动端菜单。
